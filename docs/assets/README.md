# Consumer Agent Testing Tool artwork

| Asset | Use |
| --- | --- |
| [CATT logo](catt-logo.svg) ([PNG](catt-logo.png), 1254 × 1254) | README and docs headers; the PNG for social previews and avatars |

The CATT logo is an orange cartoon cat at a desk, smiling over its shoulder,
with "CATT" spelled in code on the monitor. Its background is transparent, so it
sits on both GitHub's light and dark themes; on dark, the colored fills carry
the shape where the black outlines fade. The SVG is a
vector trace of the PNG (no embedded image, scripts or external resources).
The MIT license does not cover these files; see [TRADEMARKS.md](../../TRADEMARKS.md).
